# Environment Provider

The environment provider plugin lets Pinot discover cloud-specific instance metadata for placement and failure-domain awareness. Use this page when you need the configuration entry point rather than the plugin authoring details.

## Built-in Provider

| Provider | Purpose |
| --- | --- |
| Azure environment provider | Supplies cloud metadata for instance placement decisions |

## What this page covered

- The built-in environment provider.
- Why the provider exists in Pinot deployments.
- Where to go next if you need to add or change a provider.

## Next step

Verify the provider against your cloud environment, then check the plugin architecture docs if you need to add a new implementation.
